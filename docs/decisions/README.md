# Architecture decision records

Record one consequential decision per file. Use [the template](0000-template.md) and name files `0001-short-title.md`, `0002-short-title.md`, and so on. A proposal becomes **accepted** only after the business/technical owners agree. When a choice changes, link the replacement, move the superseded record to the history archive, fix inbound links and remove it from the active index.
