# plain updates

Lead with the result or blocker. Add the evidence that changes the owner’s decision. Use normal sentences and the names visible in the app. Keep filenames, commands and failing checks exact. A routine update can be one sentence. For a decision, state your recommendation and its practical cost. Give a full commit plan only once the task is finished.
