# review change

Establish the review base and scope first. For local work include new files and both diffs. For committed branch work inspect the merge-base comparison. Trace user-visible paths from UI through service, storage and provider where relevant. Compare actual behavior with the acceptance examples. Flag regressions with a file, location, trigger, consequence and smallest correction. Separate observed defects from outstanding verification. Give findings first. Never treat older feature plans as permission to restore outbound messaging.
