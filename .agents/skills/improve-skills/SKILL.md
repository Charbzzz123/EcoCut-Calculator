# Improve project skills

Use this skill when the owner asks to improve the project skills or a real interaction reveals that one gave confusing, incomplete, or misdirected guidance.

1. Identify the skill involved and the specific interaction evidence. Separate a skill gap from missing product information, a one-off tool failure, or an implementation defect.
2. Check the skill and nearby project rules. Propose the smallest change that would have improved the observed interaction. Do not turn one example into a broad rule without evidence.
3. Tell the owner what you observed and show the proposed instruction or new skill purpose. Ask for approval before adding, removing, or editing any skill file.
4. If the owner declines or has not answered, leave skills unchanged. Continue unrelated authorized work when possible.
5. After approval, edit only the approved skill scope. Keep each skill focused, preserve its routing and permissions, and avoid duplicating rules already covered by `AGENTS.md` or another skill.
6. Validate changed skills with the skill creator's `quick_validate.py`. Report the evidence, change, validation result, and any remaining uncertainty.

Do not silently rewrite skills based on inferred preferences. Record confirmed project preferences in the appropriate durable project guidance when they apply beyond one skill.
