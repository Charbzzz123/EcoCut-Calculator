# plan sprint

Reuse existing tracker IDs. Search for existing work before creating items. An epic is an outcome, a story delivers a usable slice, and tasks are checkboxes unless they need separate tracking. Give each story its parent, acceptance examples, blockers and relative size. Rank prerequisites first, then pilot risk, operator value and effort. Put only ready stories within available capacity into the iteration. Use the authorized project, issue links and actual field IDs. Verify parent, status and iteration after writes. If Projects access is missing, return import-ready drafts and mark them unpublished.
