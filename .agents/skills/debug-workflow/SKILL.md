# debug workflow

Start with a repeatable symptom and a synthetic record. Compare a working path and a failing path. Inspect request/response, service decisions, durable record and UI refresh until the first disagreement is identified. Use a single hypothesis and the smallest check that distinguishes it. Apply the fix at the responsible layer. Repeat the failing path and an adjacent working case. Use the relevant isolated browser or API check when the boundary matters. Report what was observed and which external behavior was mocked.
