# pr draft

Check the actual base, branch diff and the pending commit plan. Include uncommitted intended changes when drafting before the owner commits. Give a short title, operator outcome, changes, actual verification, and remaining risk or follow-up. Use the repo PR template when present. Label future work clearly. Return the draft to the owner. Opening a PR, pushing and merging are separate actions.
